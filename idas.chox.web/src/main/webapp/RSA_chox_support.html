FAQ


Session time out message

The system is designed so that your session will time out after a period of non-activity to ensure security of the system. To resolve this "Log off" and log back in.


Internet error

This may be caused either by an issue with the RSA Internet pathway or a CHOX system issue. To check the error is not an RSA issue, try accessing another external Internet page (e.g. www.bbc.co.uk). If the same error still occurs this may be an Internet issue across RSA or your site. If you are able to access another site but the issue still occurs when accessing CHOX you may need to delete your Temporary Internet files. This can be done via the "Tools" option at the top of your Internet window ("Internet options" - "Temporary Internet Files" and click on "Delete Cookies" and "Delete Files").


Password / ID error

Check you have used the correct password and ID.
